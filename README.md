# programming3

Game name: Outrun (Tag-based game)

Who Might Use It: Students that are bored in class, or new programmers

What would the user do with it: Play the game, try and get a highscore

what is one key input and possible output: ASD movement on screen

what is the smallest working version: Square moving around screen

What is one question your group needs to research: How to put a highscore.

Program steps as I understand them: The user clicks up; the program makes the user go up; then it follows the user and tries to tag them.

One part of the logic that is clear: When you press a button, like the up button, then they jump/go up.

One question or unclear step: We must decide what the characters look like and the obstacles we put.

One test case: If the user presses a, I would expect the program to make them go left.
